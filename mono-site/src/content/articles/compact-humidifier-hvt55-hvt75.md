冬の乾燥対策に加湿器を置きたいけれど、床のスペースは増やしたくない。そんなときは、本体の大きさだけでなく、同じ設置面積でどれだけ加湿できるかを比較しましょう。

今回はシャープのHV-T55とHV-T75をメーカー公表仕様から比較します。実機レビューではありません。

## 2機種の仕様比較

| 項目 | HV-T55 | HV-T75 |
| --- | ---: | ---: |
| 幅×奥行×高さ（突起部除く） | 27.2×22×45.5cm | 27.2×22×45.5cm |
| 質量 | 約5.2kg | 約5.2kg |
| タンク容量 | 約4L | 約4L |
| 加湿量（強） | 550mL/h | 750mL/h |
| 加湿量（静音） | 200mL/h | 200mL/h |
| 加湿量（エコ強） | 390mL/h | 480mL/h |
| 適用床面積・プレハブ洋室 | 15畳 | 21畳 |
| 適用床面積・木造和室 | 9畳 | 12.5畳 |
| 消費電力（強／静音／エコ強） | 190／12／24W | 335／12／34W |
| 運転音（強／静音） | 37／23dB | 41／23dB |
| 連続加湿時間（強／静音） | 約7.2／19時間 | 約5.3／19時間 |

加湿量は室温20℃・湿度30％での規格に基づく値、消費電力は室温30℃での公表値です。実際の加湿量や運転時間は室内環境によって変動します。

## 同じ面積でも加湿量は約36％違う

外形寸法の幅と奥行を掛けると、両機種とも約598平方cm。HV-T75は強運転の加湿量がHV-T55より約36％多く、広い部屋に対応します。ただし、この面積は必要設置スペースではありません。壁や家具との間隔、吸排気、給水やトレーの取り外しに必要な空間は説明書で確認してください。

## 電気代と給水頻度

31円/kWh、毎日8時間、30日間、各モードの公表消費電力で一定運転した場合の試算です。

| モード | HV-T55 | HV-T75 |
| --- | ---: | ---: |
| 強 | 約1,414円 | 約2,492円 |
| エコ強 | 約179円 | 約253円 |
| 静音 | 約89円 | 約89円 |

計算式は消費電力(W)÷1000×8×30×31。自動運転による出力変化や待機電力は含みません。エコ強は通常の強より加湿量も減るため、同等の加湿性能での電気代比較ではありません。

タンク容量は同じなので、強運転の連続時間はHV-T55の方が長くなります。両機種とも上からの注水とトレーを外しての給水に対応します。

## どちらを選ぶ？

- HV-T55：適用床面積内の寝室や小さめのリビングで、強運転の電力や給水頻度を抑えたい場合。
- HV-T75：同じ本体サイズで、より広い部屋の加湿能力を確保したい場合。

静音運転の公表加湿量と運転音は同じです。広い部屋でも静音運転だけで十分とは限らないため、湿度計で実際の湿度を確認しましょう。結露が起きる場合は加湿を控え、説明書に沿って水交換や清掃を行ってください。
